# ПостПульт

Локальное оконное приложение на Python/Tkinter для приёма постов через MAX, модерации авторов, настройки маршрутов VK/MAX/Rutube, очереди и отложенной публикации.

## Запуск

1. Установите Python 3.11+ и системный пакет Tkinter.
2. Создайте окружение: `python -m venv .venv` и активируйте его.
3. Установите зависимости: `pip install -r requirements.txt`.
4. Запустите: `python postpult.py`.

Профиль и зашифрованные токены хранятся в `~/.postpult` (или в каталоге из переменной `POSTPULT_HOME`). Не удаляйте `secret.key`: без него зашифрованные настройки восстановить нельзя.

## Подключения

- Входящие сообщения: один токен MAX.
- Публикация: отдельный токен и целевой ID для каждого маршрута категории.
- Rutube и AI подключаются через настроенные HTTPS-шлюзы, так как конкретный API-доступ зависит от выданных вам официальных реквизитов.
- Сетевые вызовы не выполняются при импорте; перед реальной публикацией проведите тест в отдельной группе/канале.

Файл проверен на синтаксис Python. Запуск GUI в среде без системной библиотеки Tkinter невозможен, но на обычной desktop-установке Python с Tkinter приложение запускается.
